# Portfolio — Tebello Masike

Cybersecurity and Data Science portfolio built with vanilla HTML, CSS, and JavaScript. Features a three-theme system (dark/light/glow), responsive timeline layout, contact form, and lazy-loaded assets.

## Live Site

[https://tebello-masike-portfolio.vercel.app/](https://tebello-masike-portfolio.vercel.app/)

## Tech Stack

- HTML5
- CSS3 (custom properties, animations, responsive grid)
- JavaScript (vanilla, Intersection Observer, localStorage)
- Vercel (hosting)

## Features

- Three theme modes — Dark, Light, Glow with persistent preference
- Animated grid background and ambient falling lines
- Timeline-based project and experience cards with reveal-on-scroll
- Lazy-loaded images with blur-up placeholder
- Contact form with EmailJS integration
- Fully responsive (mobile-first)
